# GenAI Architecture

**Principle: GenAI reads and writes; code decides.** Google Gemini turns unstructured input (a Hinglish brief, a photo of
a vendor quote, an open question) into structured facts, and writes ideas, messages and explanations. Every rupee, date,
count, rule and checklist comes from tested, deterministic engines in
[`packages/core/src/engine`](packages/core/src/engine), and every number the model writes is checked against them.
Gemini is called only from the server; the browser never sees a key or a prompt.

## Model and transport

| Item       | Value                                                                                                                                                                                                                                                                                                                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Models     | Google Gemini `gemini-3.5-flash-lite`, failing over to `gemini-3.1-flash-lite` (`LLM_MODELS`; [`llm-config.ts`](apps/server/src/llm-config.ts))                                                                                                                                                                                                  |
| Service    | The Gemini API free tier, through its OpenAI-compatible endpoint, **server-side only**                                                                                                                                                                                                                                                           |
| Transport  | An OpenAI-compatible LLM gateway ([`llm-service-caller.ts`](apps/server/src/services/llm-service-caller.ts)); the gateway URL must be on a two-origin allow-list and the upstream must be the Gemini API endpoint, or the AI stays off                                                                                                           |
| Output     | A JSON Schema generated from the zod contract ([`genai/model-schema.ts`](packages/core/src/genai/model-schema.ts)) travels in the system instruction with JSON mode; fences are stripped and the reply is zod-validated, with one second pass that drops blank strings ([`model-json.ts`](apps/server/src/services/model-json.ts))               |
| Failover   | The next model is tried on a timeout (45 s per attempt), a network error or a 400, 404, 408, 429, 500, 502, 503 or 504; the last good model goes first next time ([`genai-client.ts`](apps/server/src/services/genai-client.ts), [`failover.ts`](apps/server/src/services/failover.ts))                                                          |
| Budget     | A per-model daily guard (`LLM_DAILY_LIMITS`, default 450 a day each, 90% of the free tier's 500) resets at midnight Pacific time; a spent model is skipped ([`daily-budget.ts`](apps/server/src/services/daily-budget.ts))                                                                                                                       |
| Caching    | 50 entries × 30 minutes per service, keyed by SHA-256 of the redacted input ([`service-kit.ts`](apps/server/src/services/service-kit.ts)); what-if and rule-answered questions make no call at all                                                                                                                                               |
| Fallback   | Every job has an offline twin in [`packages/core/src/offline`](packages/core/src/offline) returning the same shape                                                                                                                                                                                                                               |
| Provenance | Every AI response carries `mode` (`gemini` or `offline`), the models tried, latency, steps and, when offline, a `reason` (`daily_quota`, `upstream_error` or `not_configured`); the UI shows "Explained by Gemini · model · seconds" or "Offline planner" ([`ProvenanceBadge.tsx`](apps/web/src/components/features/common/ProvenanceBadge.tsx)) |

The server recomputes the plan from the posted context for every job, so the facts the model sees and the facts the
guards check are the server's own ([`plan-service.ts`](apps/server/src/services/plan-service.ts),
[`ask-service.ts`](apps/server/src/services/ask-service.ts)). When Gemini answers, drafts and narration are written in
the family's chosen language, one of 11 ([`domain/languages.ts`](packages/core/src/domain/languages.ts)). The offline
planner narrates in English and drafts in English, Hindi or Hinglish; the plan's tables, checklists and "Why this?"
traces are in English in both modes.

## Safety and privacy

- **Personal details in typed and pasted text are redacted before every call**: Aadhaar, PAN, phone, email, IFSC,
  UPI, card and bank account numbers become typed placeholders
  ([`privacy/redact.ts`](packages/core/src/privacy/redact.ts)). An uploaded quote photo or PDF cannot be redacted
  before it is read, so it goes to Gemini as-is and only its transcript is redacted; the upload control says so. Guest
  lists, the spend tracker and the ledger stay in the browser and are never sent.
- **Untrusted text is fenced**: briefs, quotes, questions and host names are wrapped in per-request nonce delimiters, and
  look-alike delimiters are neutralised first ([`genai/prompt-boundary.ts`](packages/core/src/genai/prompt-boundary.ts)).
  Control, zero-width and bidi characters, including the isolates U+2066–U+2069, are stripped before anything else
  ([`security/sanitize.ts`](packages/core/src/security/sanitize.ts)).
- **The model never decides a number.** Prompts give it numbered facts and closed vocabularies
  ([`genai/prompt-rules.ts`](packages/core/src/genai/prompt-rules.ts)); the guards above replace anything that does not
  match.
- On the Gemini API free tier Google may use prompts and responses to improve its products, so Intezaam redacts personal
  details from typed and pasted text before every call and never sends guest names. A quote photo or PDF the family
  chooses to upload is sent as-is to be transcribed; the upload control says so and asks them to crop out phone numbers
  and bank details first.

## Evaluation harness

[`genai-evals.test.ts`](packages/core/src/__tests__/genai-evals.test.ts) runs a labelled battery
([`fixtures/eval-battery.ts`](packages/core/src/__tests__/fixtures/eval-battery.ts)) through the guards with scripted
model replies on every test run: faithfulness (invented amounts are swapped out), id validity, diet compliance, refusal
recall, language script and evidence substrings. A battery of 60 labelled briefs (11 English, 10 Hindi, 16 Hinglish, 9
Hinglish with dates, 14 mixed and guardrail cases) runs through the offline reader and the evidence guard in
[`offline-brief-battery.test.ts`](packages/core/src/__tests__/offline-brief-battery.test.ts). The server suite then runs
each job through the real app with a fake model: Gemini mode, offline mode, cache hits, daily quota and invented
numbers ([`apps/server/src/__tests__`](apps/server/src/__tests__)).
