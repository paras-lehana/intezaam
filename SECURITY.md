# Security

Intezaam handles a family's plans: budgets, dates, guest counts and sometimes a vendor's quote. It is built to see as
little as possible, keep nothing on the server, and never let untrusted text steer the AI or a spreadsheet.

## Data handling

- **No accounts, no database.** The server is stateless. Plans live in the visitor's browser (the last context in local
  storage, exported JSON, CSV and ICS files) and in the URL fragment of a share link, which browsers never send to a
  server.
- **Bounded memory only.** Each AI service keeps a cache of at most 50 results for 30 minutes, keyed by a SHA-256 of the
  redacted input.
- **Logs** are one structured JSON line per request: request id, method, route pattern, status, latency and whether the
  client came through Cloudflare. Never bodies, query strings, raw paths or IP addresses
  ([`middleware/request-log.ts`](apps/server/src/middleware/request-log.ts)).

## Error envelope

Every error has the same shape and a status from one table ([`errors.ts`](packages/core/src/errors.ts)):

```json
{ "error": { "code": "VALIDATION_FAILED", "message": "…fixed, user-safe copy…" } }
```

## Responsible AI

- **Planning help, not quotes, bookings or legal advice.** Every estimate links its source and a confidence grade, and
  grade-D values are labelled assumptions; the standing note says to get three written quotes. Ask declines booking,
  payment and legal advice whatever the model says.
- **Hedged dates and rules.** Muhurat dates are indicative ("confirm with your family priest"); permissions say "verify
  with your local police and municipal office"; a tradition is never inferred.
- **Provenance everywhere.** Every AI response says whether Gemini or the offline planner wrote it, which model, how long
  it took, and why the offline planner answered.
- **Free-tier privacy.** On the Gemini API free tier Google may use prompts and responses to improve its products, so
  Intezaam redacts personal details from typed and pasted text before every call and never sends guest names. A quote
  photo or PDF the family chooses to upload is sent as-is to be transcribed; the upload control says so and asks them
  to crop out phone numbers and bank details first.

## Reporting a vulnerability

Please open a private security advisory on GitHub (Security → Advisories → Report a vulnerability). We aim to acknowledge
within 7 days.
